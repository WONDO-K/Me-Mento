# Me-mento 개인정보처리방침

검토 초안 · 2026-11-27 · 한국 이용자를 대상으로 한 제품 V1 기준

> 출시 전 검토용 문서입니다. 운영 주체, 실제 처리 항목, 위탁·국외 이전, 보유기간과 권리 행사 경로를 확정한 뒤 시행일을 기재합니다.

## 1. 개인정보처리자와 적용 범위

- 서비스명 · Me-mento
- 개인정보처리자 · **[확정 필요 — 법인명 또는 사업자명]**
- 개인정보 보호 문의 · **[확정 필요 — 담당 부서 또는 책임자, 이메일과 권리 행사 접수 경로]**
- 시행일 · **[확정 필요 — 공개 및 적용 시작일]**

이 방침은 Me-mento iPad 앱과 공개 노트 서비스를 이용할 때 처리하는 개인정보에 적용합니다. 이 앱에서 기기 내 노트를 편집하는 기능과, 계정으로 공개·검색·복사·즐겨찾기를 이용하는 기능은 서로 다른 데이터를 사용합니다.

## 2. 처리하는 항목, 목적과 수집 경로

| 상황 | 처리 항목 | 처리 목적과 경로 |
|---|---|---|
| Google 또는 Apple로 로그인 | 로그인 제공자, 검증된 제공자 사용자 식별자, Me-mento 계정 식별자 및 세션 정보. 이메일 수신·저장 여부는 **[확정 필요]** | 이용자를 인증하고 세션을 유지합니다. 이용자가 선택한 로그인 제공자에서 인증 결과를 받습니다. |
| 노트 공개와 관리 | 공개 표시 이름, 계정과 공개 노트의 연결, 제목·태그·선택 소개, 공개한 필기·메모·마인드맵, 공개 상태·복사 권한과 버전, 사본의 출처 | 이용자가 공개를 확정할 때 선택한 버전을 서버에 저장해 공개하고, 업데이트·비공개 전환·작성자 권한을 관리합니다. |
| 즐겨찾기와 전체 복사 | 계정과 즐겨찾기한 공개 노트의 연결, 복사 대상·버전, 요청 및 완료 확인에 필요한 기록, 사본 출처와 재공개 권한 정보 | 즐겨찾기를 불러오고 복사 권한과 출처를 확인하며, 완료 복사를 중복 없이 집계합니다. 공개 노트의 작성자에게는 자신의 공개 노트의 완료 복사 횟수를 제공합니다. |
| 신고·운영 조치 및 문의 | 신고 또는 문의를 보낸 계정이나 문의에 제공한 연락처, 대상 공개 노트와 버전, 사유·선택 설명, 처리 기록 및 파생본 안내 이력 | 신고에 대응하고 조치 결과와 필요한 안내를 전달하며 문의를 처리합니다. |
| 서비스 안정성과 보안 | **[확정 필요 — 서버·인증 업체가 만드는 IP 주소, 요청·인증 로그, 오류 진단 정보 등의 실제 수집 여부, 항목과 보유기간]** | 접근 제어, 장애 대응, 보안과 함께 로그를 실제로 사용하는 목적을 확정해 고지합니다. |

정해진 목적의 범위에서 필요한 항목을 처리합니다. 선택 소개나 신고 보충 설명에는 이용자나 다른 사람을 식별할 수 있는 정보를 불필요하게 입력하지 않도록 안내합니다. Google 또는 Apple 로그인에 사용하는 이메일은 공개 작성자 표시 이름과 별도로 다룹니다. 서비스가 Google·Apple에서 요청하는 권한과 제공자로부터 받는 항목은 출시 설정을 확인해 확정합니다.

## 3. 기기 내 노트와 직접 만든 백업

- **개인 노트**는 iPad에 저장됩니다. 필기, 메모, 마인드맵, 개인 태그, 가져온 문서와 공개 후 편집한 작업 내용이 포함됩니다. 로그인만으로 기기 내 개인 노트가 Me-mento 서버에 동기화되지는 않습니다.
- **로그아웃과 계정 전환** 뒤에도 이 iPad의 개인 노트는 남습니다. 같은 iPad에서 다른 계정으로 로그인하면 같은 기기 내 노트가 보일 수 있습니다. 공개본 관리와 즐겨찾기에는 각각 해당 계정의 권한과 기록이 적용됩니다.
- **수동 전체 백업**에는 기기 내 노트와 첨부 자료, 개인 태그, 복사 출처와 공개 제한 정보가 들어갑니다. 로그인 자격 증명과 서버의 즐겨찾기·공개 관리 권한은 백업에 포함하지 않습니다. 이용자가 iCloud Drive나 다른 외부 저장소를 선택하면 해당 저장소의 설정과 정책이 백업 파일에 적용됩니다.
- **PDF·워드 가져오기**로 만든 노트는 첫 버전에서 개인용으로 사용합니다. 원래 페이지와 그 위에 쓴 필기·메모를 기기에 보관합니다. 외부 워드 변환을 채택하는 경우 **[확정 필요 — 전송 항목·목적·업체·보유기간·처리 국가 및 적용 근거]**를 확인해 실제 도입 전에 반영합니다.

## 4. 공개 노트와 복사 시 정보의 공개 범위

- 이용자가 **전체 공개**를 확정하면 그 시점의 노트가 공개본으로 처리됩니다. 처리가 완료되면 로그인한 다른 이용자가 공개 표시 이름, 제목·태그·소개, 필기·메모·마인드맵 전체와 관련 출처를 볼 수 있습니다. 공개 처리 중에 새로 편집한 내용은 다음 업데이트에서 공개할 수 있습니다.
- 공개할 때 **복사 허용** 또는 **열람만 허용**을 선택합니다. 복사 허용 노트의 경우 다른 이용자가 공개본을 내려받아 자기 기기에 편집용 사본으로 저장할 수 있습니다. 출처를 유지한 무료 재공개가 가능하며, 노트 사본의 판매는 허용하지 않습니다. 열람만 허용하는 경우 다른 이용자는 공개본을 열거나 즐겨찾기할 수 있습니다.
- 복사 허용에서 열람 전용으로 변경하거나 공개를 중단하면 새 복사를 제한합니다. 이미 다른 이용자의 iPad에 저장된 사본은 그 기기에 남습니다. 독립적으로 공개한 수정본과 해당 출처 기록은 원본의 일반적인 비공개 전환만으로 삭제되지 않습니다.
- 공개본에 개인정보가 포함되어 있어 열람을 중단하거나 삭제할 필요가 있다면 아래 접수 경로로 요청할 수 있습니다. 원본과 파생 공개본의 조치, 계정 삭제 뒤 남는 출처 표시의 범위 및 기간은 **[확정 필요 — 개인정보 권리 처리, 공개본·사본·계보별 처리 방침]**에 따릅니다.

## 5. 보유기간과 파기

| 데이터 | 보유 및 삭제 기준 |
|---|---|
| 계정과 세션 | 이용 중 처리합니다. 계정 삭제와 세션 폐기의 실제 완료 시점, 별도 보존 항목과 기간은 **[확정 필요]**입니다. |
| 공개 노트와 이전 버전, 출처 | 공개 관리와 사본 출처 확인에 사용합니다. 비공개 전환은 다른 이용자의 접근을 중단하는 동작입니다. 공개 중단·삭제·계정 삭제 이후 본문과 표시 정보의 보유기간, 접근 범위, 삭제·비식별화 여부는 **[확정 필요]**입니다. |
| 즐겨찾기와 복사 집계 | 즐겨찾기 해제·계정 삭제 이후 연결 기록, 집계의 보존·익명화 시점은 **[확정 필요]**입니다. |
| 신고·문의·운영 기록과 보안 로그 | 기록 종류별 처리 목적과 기간, 법령에 따라 보존하는 경우 그 근거와 항목은 **[확정 필요]**입니다. |
| 서버 백업과 복구본 | 서비스 백업에 포함하는 항목, 암호화·접근 제한, 삭제 내용이 백업에 반영되는 최대 기간은 **[확정 필요]**입니다. |

처리 목적이 달성되거나 보유기간이 끝난 정보는 적용되는 법령에 따른 보존 사유가 있는 경우를 제외하고 파기합니다. 별도 보존이 필요한 경우 보존 근거와 기한을 적용하고 접근을 제한합니다. 전자 파일은 복구·재생이 어렵도록 삭제하는 방법을 적용하며, 실제 저장소와 백업의 파기 방법은 **[확정 필요]**입니다.

Me-mento의 계정 삭제와 iPad 저장소·수동 백업 파일의 삭제는 별도입니다. 계정 삭제 화면에는 각 자료의 처리 결과와 이용자가 기기 또는 파일 앱에서 별도로 조치할 항목을 안내합니다.

## 6. 제3자 제공, 처리 위탁과 국외 이전

공개 노트의 열람·복사 범위는 제4절에 설명되어 있습니다. 공개 기능 외의 개인정보 제3자 제공, 처리 위탁, 국외 저장이나 접속은 실제 운영과 계약을 확인해 아래 항목을 완성합니다. Apple·Google 로그인은 인증을 위해 이용자가 선택하는 외부 서비스입니다. 제공자와 Me-mento 양쪽에서 처리하는 정보는 로그인 권한과 각 제공자의 정책에서 확인할 수 있습니다. [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/ko/) · [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)

| 구분 | 출시본에 확인할 내용 |
|---|---|
| 제3자 제공 | **[확정 필요 — 해당 여부, 제공받는 자, 목적, 항목, 보유기간과 근거]** |
| 처리 위탁 | **[확정 필요 — 호스팅·인증·첨부 저장·문의·오류 진단 등 실제 수탁자와 위탁 업무, 관련 재위탁]** |
| 국외 이전 | **[확정 필요 — 해당 여부와 적용 근거, 이전 항목, 이전 국가·시기·방법, 이전받는 자와 연락처, 목적·보유기간, 거부 방법과 효과]** |

## 7. 이용자의 권리와 행사 방법

이용자는 적용되는 법령에 따라 개인정보의 열람, 정정·삭제, 처리정지 등을 요청할 수 있습니다. 동의가 근거인 처리에 대해서는 동의 철회를 요청할 수 있습니다. 요청은 제1절의 문의 경로나 **[확정 필요 — 앱 내 계정 삭제 및 권리 행사 메뉴 경로]**에서 접수합니다. 대리인이 요청하는 경우 필요한 범위에서 대리권을 확인합니다.

요청자의 본인 여부를 필요한 범위에서 확인한 뒤 처리 결과를 알려드립니다. 법령에 따른 제한이나 별도 보관이 적용되는 경우 이유를 안내합니다. 이용 연령과 만 14세 미만 이용자의 가입 지원 여부, 해당하는 경우 법정대리인 동의와 권리 행사 방법은 **[확정 필요]**입니다.

## 8. 안전성 확보와 진단 기능

계정 인증, 서버의 접근 권한 검증, 공개·운영 조치 권한 분리, 개인정보 접근 범위 제한을 적용하는 것을 설계에 포함합니다. 전송·저장 보호, 접근 기록 관리, 운영자 권한 관리, 파기 절차는 실제 배포 구성을 확인한 뒤 적용되는 조치를 안내합니다.

광고와 이용 행태 분석은 현재 V1 범위에 포함되어 있지 않습니다. **[확정 필요 — 실제 포함된 SDK의 자동 수집 항목, 목적과 설정·거부 방법]**을 출시 전에 확인합니다. 파일럿에서 별도 원격 분석을 도입하면 수집 항목·보유기간과 적용 가능한 이용자 안내를 먼저 확정합니다.

## 9. 문의와 처리방침 변경

개인정보 관련 문의와 권리 행사는 제1절의 담당 접수 경로를 이용할 수 있습니다. 관련 기관의 분쟁조정·침해 신고 경로는 한국 출시본에 안내합니다. [개인정보침해 신고센터](https://privacy.kisa.or.kr/) · [개인정보분쟁조정위원회](https://www.kopico.go.kr/)

처리방침을 변경할 때에는 변경 내용과 적용일을 앱 또는 앱에서 접근할 수 있는 정책 페이지에 안내합니다. 별도 동의가 필요한 변경은 적용되는 절차에 따라 처리합니다. 이전 시행본과 변경 이력을 함께 확인할 수 있도록 관리합니다.

## 출시 승인 메모

이 절은 팀 검토용이다. 공개 페이지에서는 확정된 처리방침 본문과 시행 이력을 제공한다.

1. 출시 주체와 대상 국가·연령, 책임자, 문의 경로와 시행일을 확정한다. 대한민국 기준으로 개인정보처리방침 공개 항목과 실제 처리 근거를 점검한다. [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법)
2. Google·Apple 로그인 설정, API·첨부 저장, 문의 도구, 운영 콘솔, SDK와 앱의 네트워크 요청을 대조해 실제 데이터 목록과 처리업체·국가를 작성한다. 가져오기와 백업에 외부 전송이 생기는 조건도 확인한다.
