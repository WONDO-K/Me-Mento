# Me-mento 문서 변경 이력

문서 묶음을 확정한 이유와 영향을 받은 문서를 최신순으로 기록한다. [현재 문서 목록과 버전 관리 규칙](README.md)에서 평소 편집 경로를 확인할 수 있다.

## v0.2 · 로드맵과 제품 문서 통일

- **보관 등록** · 2026-11-27
- **기준 커밋** · `049a773`
- [v0.2 문서 묶음](versions/v0.2/README.md)

| 영향 문서 | 변경 내용과 이유 |
|---|---|
| 로드맵 | M6 검증과 공개 배포를 구분했다. V1의 작성자용 완료 복사 횟수를 반영해 인기순과 보상의 선행 조건을 채택한 지표에 맞췄다. R-19~R-22. |
| 기획서·구현 명세서 | V0~V4의 적용 범위를 명확히 했다. 공개 확정 시점의 내용을 고정하고 처리 성공 후 노출하도록 통일했다. 공개 처리 중 새로 쓴 메모는 기기 내 작업에 남는다. PUB-01, V-12. |
| 출범 계획서 | V0를 M0~M2, V1을 M3~M6에 매핑했다. M5의 관찰을 후속 후보 검토로 연결하고 M6에서 배포 조건을 판단하도록 명확히 했다. |
| UX 스토리보드·필기 구현 계획 | V0의 첫 화면은 한 페이지 편집기이고, V1에서 홈·최근 노트와 공개·복사가 이어진다는 점을 맞췄다. UX-01, UX-02. |
